# 4.- Repositorio: Github

GitHub es la plataforma de alojamiento de código y colaboración más grande del mundo. Fundada en 2008 y adquirida por Microsoft en 2018, GitHub ofrece todo el control de versiones distribuido y la gestión de código fuente (SCM) de Git, pero le añade sus propias características. Es vital entender la diferencia: Git es la herramienta de línea de comandos subyacente; GitHub es el servicio web que aloja los repositorios Git en la nube.

GitHub transformó el desarrollo de software al introducir el concepto de "Social Coding". Antes de GitHub, colaborar en proyectos de código abierto (Open Source) requería enviar parches de código por listas de correo electrónico, un proceso tedioso. GitHub democratizó esto permitiendo a cualquier persona copiar un proyecto (Fork), modificarlo libremente, y solicitar al creador original que incorpore esas mejoras mediante una interfaz web sencilla.

**Ecosistema de GitHub:**
Más allá de alojar código, GitHub se ha convertido en una suite completa para el ciclo de vida del desarrollo:

* **Issue Tracking:** Un sistema integrado para reportar errores, solicitar nuevas funcionalidades y gestionar tareas.
* **GitHub Actions:** Su motor nativo de Integración y Entrega Continua (CI/CD) que permite automatizar pruebas, análisis de seguridad y despliegues directamente en los servidores cada vez que alguien sube código nuevo.
* **GitHub Pages:** Alojamiento gratuito de sitios web estáticos generados a partir de repositorios Markdown.
* **Seguridad:** Análisis automático de vulnerabilidades en las dependencias de los proyectos (Dependabot).
